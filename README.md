# 発音バトル

日本語・英語・ラオス語・キューバスペイン語・マレー語を、1台の端末で交互に発音して競うPWAです。

## 主な機能

- 5言語の問題を自由に組み合わせて出題
- ブラウザの読み上げ機能によるお手本音声
- マイク録音と録音音声の再生
- 音声認識結果と正解語の編集距離による0〜100点の簡易採点
- 2人の交互対戦と合計点表示
- 平均点、対戦数、苦手な言語・発音項目を端末内に保存
- ホーム画面追加とオフライン表示に対応

## GitHub Pagesで公開

1. GitHubで新しいリポジトリを作ります。
2. このフォルダ内のファイルをリポジトリ直下へアップロードします。
3. GitHubの `Settings` → `Pages` を開きます。
4. `Deploy from a branch`、`main`、`/(root)` を選んで保存します。
5. 表示されたURLをiPhoneのSafariで開きます。
6. 共有ボタンから「ホーム画面に追加」を選びます。

## 動作上の注意

- マイク機能にはHTTPSが必要です。GitHub PagesはHTTPSなので利用できます。
- iPhoneではSafariを使用してください。初回にマイク利用の許可が表示されます。
- 音声認識の対応言語と精度はOS・ブラウザに依存します。特にラオス語は自動認識できない端末があるため、手動採点も用意しています。
- 現在の採点は「音声認識された文字が正解文にどれだけ近いか」を測る簡易方式です。音素や声調を直接解析する医学的・言語学的な精密評価ではありません。
- 成績は `localStorage` に保存され、外部サーバーへ送信しません。

## ローカル確認

ファイルを直接開くのではなく、ローカルサーバーを利用してください。

```bash
python -m http.server 8000
```

その後、ブラウザで `http://localhost:8000` を開きます。

## 問題の追加

`app.js` 冒頭の `LANGUAGES` に問題を追加できます。`accept` には音声認識で正解とみなす表記を複数登録できます。
